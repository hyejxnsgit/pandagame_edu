# 대나무숲 한 문장

초등 6학년 ~ 중학교 1학년 영어 문법(전치사·접속사) 연습용 3D 웹 게임입니다.
학생이 영어 문장을 직접 쓰고, 맞으면 대나무숲 광장의 빛나는 자리로 걸어가 그 문장을 크게 외칩니다.
온라인 1:1 영어 멘토링 수업을 위해 만들었고, HTML 파일 하나로 설치 없이 실행됩니다.

- 만든 사람: 최혜진 (제주대학교 컴퓨터교육과)
- 라이선스: MIT (게임 코드) · 사용한 라이브러리와 글씨체는 [라이선스](#라이선스) 참고

## 교육에 활용하기

| 항목 | 내용 |
|---|---|
| 대상 | 초6 ~ 중1 |
| 단원 | 전치사·접속사 (문제만 바꾸면 다른 문법 단원·다른 과목에도 사용 가능) |
| 수업 안 위치 | 개념을 배운 직후 연습 단계, 또는 단원 총정리 시간 (약 8분) |
| 형태 | 온라인 1:1이 기본. 교실·숙제 활용은 아래 참고 |

**이 게임으로 하는 것**
- **쓰기:** 보기 없이 영어 문장을 직접 씁니다. 객관식으로는 확인할 수 없는 산출 능력을 봅니다.
- **말하기:** 맞힌 문장을 소리 내어 외칩니다.
- **듣기:** 메아리 음성으로 정확한 발음을 한 번 더 듣습니다.
- **몸 쓰기·긴장 풀기:** 걸어가서 외치는 동작이 온라인 수업의 긴장을 풀어 줍니다.
- **구조 의식:** 핵심 문법 힌트(`during + the break`)가 처음부터 보여서 "무엇 뒤에 무엇이 오는가"를 의식하며 씁니다.

**운영 방법**
- **온라인 1:1:** 학생이 링크를 자기 기기에서 열고, 교사는 화면공유로 지켜봅니다. 주의점은 [수업에서 쓸 때](#수업에서-쓸-때-화상-수업)를 봅니다.
- **교실 (1:다수)** *(아직 실제 수업에서 확인하지 않은 방법)*: 대형 화면에 띄우고 한 명씩 나와 문장을 씁니다. 맞으면 반 전체가 함께 외치고, 교사가 스페이스바로 판정합니다.
- **숙제** *(아직 실제 수업에서 확인하지 않은 방법)*: 링크를 보내 혼자 12그루 키우기에 도전하게 합니다. 다음 수업에서 어느 문제에서 힌트를 봤는지 물어봅니다.

**기록·피드백**
- 두 번 이상 틀려 힌트 조각을 본 문제는 다음 수업 복습 1순위로 둡니다.
- 문항별로 🟢 한 번에 / 🟡 힌트 후 / 🔴 힌트를 줘도 못 함 으로 표시해 두면 다음 수업 설계에 바로 쓸 수 있습니다.

## 실행

**바로 해 보기:** `dist/` 의 HTML 파일을 내려받아 크롬에서 엽니다.

**인터넷 주소로 나눠 주기 (GitHub Pages):**
1. 배포용 HTML 파일 이름을 `index.html`로 바꿔 저장소에 올립니다.
2. 저장소 Settings → Pages에서 브랜치를 선택하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.
3. 마이크는 `https` 주소에서만 켜지므로, 학생에게는 이 주소를 보내면 됩니다.

참고
- 별도 CSS·JS 파일은 필요 없습니다. three.js, 스타일, 게임 코드가 모두 HTML 안에 들어 있습니다.
- 외부에서 불러오는 것은 Pretendard 글씨체(jsDelivr CDN) 하나뿐입니다. 오프라인이면 시스템 글씨체로 바뀌고 게임은 그대로 작동합니다.
- 다른 페이지 안의 미리보기 창(iframe)에서는 소리·마이크가 막힐 수 있습니다. 새 탭에서 엽니다.

## 조작

| 동작 | 방법 |
|---|---|
| 걸어 다니기 | 방향키 / WASD, 또는 가고 싶은 곳을 화면에서 누르기 (태블릿) |
| 외치기 | 마이크에 대고 크게 말하기. 마이크가 없으면 스페이스바를 누르고 있기 |
| 정답 제출 | 입력창에서 Enter 또는 확인 버튼 |
| 소리 끄기 | 오른쪽 위 🔊 버튼 |

- 판다는 돌 광장 원 밖으로 나가지 않습니다.
- 입력창에 글을 쓰는 동안에는 방향키가 판다를 움직이지 않습니다.
- 외치기 게이지는 판다가 빛나는 자리 안에 있을 때만 찹니다.

## 수업에서 쓸 때 (화상 수업)

- **마이크로 진짜 외치게 하려면 학생이 링크를 자기 기기에서 직접 열어야 합니다.** 화면공유만으로는 학생 목소리가 게임에 닿지 않습니다.
- 교사 화면으로 진행할 때는 학생이 외치는 것을 듣고 교사가 스페이스바로 판정합니다.
- 교사도 게임 소리를 들으려면 학생이 화상 회의 앱에서 컴퓨터 소리 공유를 켜야 합니다.
- 태블릿은 화상 회의 앱이 마이크를 쓰는 중이면 게임이 마이크를 못 잡을 수 있습니다. 이때도 교사 판정으로 진행합니다.
- 실제로 소리를 지르는 게임이므로, 수업 시간대에 가족·이웃 상황이 괜찮은지 미리 확인합니다.

## 문제 고치기

`src/game.js` 맨 위의 `QUESTIONS` 배열을 고칩니다. 문제 하나는 아래 모양입니다.

```js
{
  unit: '전치사 · during',                                   // 문제 위 작은 라벨
  ko: '쉬는 시간 동안 나는 친구와 만화책을 읽었습니다.',        // 문제 (한국어 문장)
  answers: ['i read comics with my friend during the break', // 정답으로 인정할 답들
            'during the break i read comics with my friend'],
  show: 'I read comics with my friend during the break.',    // 외치기·메아리에 쓰는 문장
  chunks: ['during the break', 'I read', 'with my friend', 'comics'], // 2번 틀리면 보여 줄 조각
  pre: ['during', 'the break', '명사 덩어리'],               // 처음부터 보이는 핵심 힌트
  why: 'during 뒤에 the break(명사 덩어리)가 왔습니다 → 전치사', // 정답 해설
}
```

- `answers`는 **소문자, 마침표·쉼표 없이** 적습니다. 판정할 때 입력값도 소문자로 바꾸고 마침표·쉼표·물음표·느낌표와 겹친 공백을 지운 뒤 비교합니다.
- 어순이 다른 정답(예: 접속사절을 앞에 쓰는 문장)도 인정하려면 `answers`에 따로 넣어야 합니다.
- 목표 그루 수는 `GOAL` 상수(기본 12)입니다. 문제가 12개보다 적으면 순환하며 나옵니다.

## 다른 과목으로 바꾸기

게임 틀(쓰기 → 정답 → 걸어가서 외치기)은 그대로 두고 **문제와 몇 군데 문구만** 바꾸면 다른 과목에도 쓸 수 있습니다.

**어울리는 과목·활동**
- 국어: 맞춤법 고쳐 쓰기, 속담·사자성어 완성, 문장 성분 넣어 문장 만들기
- 사회: 개념어 정의 쓰기 ("민주주의란 ___")
- 과학: 핵심 원리 한 문장으로 쓰기 ("물이 끓는 온도는 ___")
- 수학: 답이 하나로 정해지는 계산 (`x = 3`처럼 형식이 정해진 답)
- 제2외국어: 영어와 같은 방식 그대로

외친다는 특성상 **소리 내어 말할 만한 짧은 문장이 답인 문제**가 가장 잘 맞습니다. 서술형처럼 답이 여러 갈래인 문제는 정답 판정이 어렵습니다.

**바꿔야 하는 곳**

| 위치 | 바꿀 것 | 예 (국어) |
|---|---|---|
| `src/game.js` → `QUESTIONS` | 문제·정답·힌트·해설 전부 | `ko: '다음 문장을 맞춤법에 맞게 고쳐 쓰세요: 어의없다'` |
| `src/game.js` → `norm()` 함수 | 정답 비교 규칙 | 한국어는 띄어쓰기까지 무시하려면 `.replace(/\s+/g, '')` 추가 |
| `src/game.js` → `speakEcho()` | 메아리 언어 | `u.lang = 'ko-KR'`, 목소리 찾기를 `/ko/i`로 |
| `src/shell.html` | 입력창 안내 문구, 시작 화면 설명 | `placeholder="여기에 영어 문장을…"` → `"여기에 답을…"` |
| `QUESTIONS`의 `pre` | 힌트 꼬리말 | `'명사 덩어리'` → `'맞춤법 포인트'` |

**과목별로 주의할 점**
- **한국어 답:** 띄어쓰기 하나로 오답이 되기 쉽습니다. 띄어쓰기를 평가하는 문제가 아니라면 비교할 때 공백을 지우도록 바꿉니다.
- **수학 답:** `x=3`, `x = 3`, `3` 처럼 같은 답을 여러 모양으로 씁니다. 받아 줄 모양을 `answers`에 모두 넣거나, 숫자만 뽑아 비교하도록 바꿉니다.
- **메아리 음성:** 한국어 문장이면 `ko-KR`로 바꾸지 않으면 영어 발음으로 읽습니다.
- 바꾼 뒤에는 **모든 정답 모양을 직접 입력해** 통과하는지 확인합니다.

## AI로 보완하기

이 게임은 **HTML 파일 하나**로 되어 있어서 AI에게 고쳐 달라고 하기 쉽습니다. 코딩을 몰라도 아래 순서대로 하면 됩니다.

### 기본 순서

1. **원본을 복사해 둡니다.** 고친 파일이 이상하면 되돌릴 수 있게 합니다.
2. **AI에게 이 README와 고칠 파일을 함께 줍니다.**
   - 문제만 바꿀 때: `src/game.js` 맨 위 `QUESTIONS` 부분만 복사해서 줘도 됩니다.
   - 기능·과목을 바꿀 때: `src/game.js`와 `src/shell.html` 전체를 줍니다.
   - `dist/`의 배포용 HTML은 three.js가 들어 있어 매우 깁니다. AI에게는 `src/`의 두 파일을 줍니다.
3. **원하는 것을 구체적으로 말합니다.** 아래 예시 문장을 그대로 고쳐 쓰면 됩니다.
4. **받은 코드를 붙여 넣고 [빌드](#빌드)를 실행**한 뒤 브라우저로 엽니다.
5. **수업 전에 직접 한 판 끝까지** 해 봅니다. 정답을 모두 넣어 보고, 틀린 답도 넣어 봅니다.

## 개발자용

### 저장소 구조

```
├── README.md
├── LICENSE
├── src/
│   ├── shell.html      화면 틀과 CSS (/*THREE*/, /*GAME*/ 자리에 스크립트가 들어감)
│   └── game.js         게임 코드 (3D 장면, 이동, 판정, 소리)
└── dist/
    └── index.html      src + three.js(r147)를 합친 배포용 단일 파일
```

`node_modules/`는 저장소에 올리지 않습니다 (`.gitignore`).

### 빌드

`src/`를 고친 뒤 아래를 실행하면 `dist/index.html`이 새로 만들어집니다.

```bash
npm i three@0.147.0   # 처음 한 번
python3 - <<'EOF'
shell = open('src/shell.html', encoding='utf-8').read()
three = open('node_modules/three/build/three.min.js', encoding='utf-8').read()
game  = open('src/game.js', encoding='utf-8').read()
out = shell.replace('/*THREE*/', three).replace('/*GAME*/', game)
open('dist/index.html', 'w', encoding='utf-8').write(out)
EOF
```

three.js는 r147을 씁니다. 전역 `THREE`를 쓰는 `three.min.js`가 r150 이후 빠졌기 때문입니다.
